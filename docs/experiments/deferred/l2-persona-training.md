# L2 人格语料收集清单（数字分身 · LoRA 微调准备）

> 配套《需求文档》（`docs/requirements/PRD.md`）人格层章节。**不绑定 PRD 版本号**——本文件为 `deferred` 实验记录，版本随动会造成无意义漂移；当前 PRD 版本以 `docs/baseline.yml` `artifacts.prd` 为准。
> 决策 B（2026-08-04 确认）：MVP 用 L1（提示词人格卡）上线；**同时收集本人语料，规划 L2 LoRA 微调**，使口吻更"长在骨子里"。生产环境始终保留 L1 作为 fallback，保证稳定。

---

## 0. 背景与定位

- **事实层 = RAG**（与你毕业设计同款：Qwen2.5 + 文档投喂 + 向量相似度检索）。RAG 不修改模型权重，是"检索增强生成"的标准架构。
- **人格层**分三级：
  - L1：提示词人格卡（persona card + few-shot），MVP 即用，零训练成本；
  - **L2：LoRA 轻量微调**，在基座模型上注入"你本人"的口吻/情商/逻辑；
  - L3：全参微调，最重，作可选增强。
- 本清单为 **L2 准备**：把"你本人"的文本攒成训练语料，待条件成熟做一次轻量 LoRA。

## 1. 语料类别与建议量级

| # | 类别 | 来源 | 建议有效条数 | 优先级 | 收集状态 |
|---|------|------|--------------|--------|----------|

---

## 2. 格式规范

- 统一为对话样本（推荐）：
  ```json
  {"messages":[
    {"role":"user","content":"你在 XX 项目里具体负责什么？"},
    {"role":"assistant","content":"我主要负责……（用你本人的口吻答）"}
  ]}
  ```
- 或指令格式：`instruction` / `input` / `output`（input 可空）。
- 编码 UTF-8；去重；去乱码与无关符号。
- 单条长度建议 ≤ 1500 字；过长切片。
- 文件名按类别归档：`01-self-intro/`、`02-im/`、`03-email/` …

---

## 3. 脱敏规则（重要）

- 去除：真实姓名、手机号、身份证号、邮箱地址、家庭住址、公司机密。
- 他人隐私：用占位符（如「某同事」「A 公司」）替换，仅保留**表达风格**。
- 不保留敏感事实：语料目标是"像你说话"，不是"泄露你隐私"。
- 训练优先在本地 / 租卡环境完成，产物（LoRA 权重）不公开含隐私内容。

## 4. 训练计划（草案，待执行）

| 项 | 建议 |
|----|------|
| 基座模型 | Qwen2.5 系（与你毕业设计一致，便于衔接与复现） |

---

## 5. 与 L1 的对照评估

- **盲测**：准备 10–20 组问题，分别用 L1、L2 生成回答，让不熟悉的人判断"哪段更像你"。
- **指标**：口吻一致性、情商恰当性、是否不编造事实、是否越界本人口吻拒答。
- **决策**：L2 仅在盲测明显优于 L1 时才切换生产；否则 L1 继续扛，L2 作实验记录。

## 7. 风险与回退

- L2 训练失败 / 不稳 / 效果不及预期 → **L1 始终作为生产 fallback**，不影响上线。
- 隐私泄露风险 → 严格脱敏 + 本地/租卡训练，不公开含隐私产物。
- 成本超预期 → 仅做最小实验（300 条 + 短训练）验证即可，不必一次性全量。
